智识图库是一套面向个人与团队的图片资产平台。它把上传、审核、检索、分析、权限与实时协同串成完整链路，并通过对象存储、分片路由和多级缓存实验，探索图库业务从功能可用到工程可扩展的实现方式。

PROJECT OVERVIEW

围绕图片全生命周期搭建业务闭环

项目不是孤立功能的堆叠，而是以“空间”为业务边界，把图片、成员、权限、容量、分析与协同组织到同一套领域模型中。

01

三类使用语境

公共图库承接浏览与审核，私有空间服务个人资产，团队空间通过成员角色支持协作；同一张图片在不同空间下进入不同的鉴权路径。

PUBLIC公共图库

公开浏览、上传审核、管理员治理

→
PRIVATE私有空间

个人资产、容量配额、独立管理

→
TEAM团队空间

角色权限、成员管理、实时协同

AI 智能扩图

接入阿里云异步任务接口，创建扩图任务后轮询状态，将生成式图像能力嵌入原有图片编辑流程。

◎

空间数据分析

从容量用量、分类、标签、尺寸、成员贡献和空间排行六个视角理解资产结构与使用情况。

✓

审核与批量治理

公共图片包含待审核、通过、拒绝状态；管理员可以批量导入、编辑与审核，形成平台治理入口。

⚡

性能与扩展探索

保留 Caffeine → Redis → DB 双层缓存实验路径，以随机 TTL 抖动缓解雪崩；按空间 ID 实现 ShardingSphere 自定义分片算法。

SPACE-LEVEL RBAC

权限不是散落在接口里的 if-else

角色—权限关系由 JSON 集中配置，接口只声明需要的权限；Sa-Token 从请求上下文识别 pictureId / spaceId / spaceUserId，再解析当前用户在对应空间的最终权限。

一次注解鉴权的解析路径

  1. 接口声明@SaSpaceCheckPermission("picture:edit")
  2. 提取上下文从 JSON / query 与 URL 模块识别业务 ID
  3. 定位空间pictureId → Picture → spaceId
  4. 解析角色公共 / 私有 / 团队空间分别处理
  5. 返回权限配置映射成 permissionList 交给 Sa-Token
