项目概览

一个注册中心，四类 AI 资产

AgentHub 把分散在各人电脑、各仓库的 AI 能力沉淀为团队级共享资产——Skill（能力单元）、Agent（编排应用）、MCP Server（工具服务）、Prompt（提示词），统一发布、版本化、审核、检索。

Skill · 可复用能力单元

以 zip 包上传的工具/提示词/文件集合，AI 客户端拉取后即装即用。支持文件夹自动打包、Git 仓库、Docker 镜像等多种来源。

MCP Server · 工具服务

实现 Model Context Protocol 的工具/资源服务，可被任意 AI 客户端调用。登记后可一键部署到运行环境，拿到连接地址。

Agent · 编排应用

由多个 MCP Server、Skill、提示词编排而成的 AI 应用，定义完整的能力组合与交互。

Prompt · 提示词模板

内置 search_registry / deploy_mcp_server 等模板，也支持团队沉淀通用提示词，复用经验。

审批 + 可见性双闸门

发布进入 pending → 管理员审批为 active → 设可见性（public/internal/private/owner-only）后才被他人看到。

三种使用方式

按推荐顺序：对话、网页、命令行

为不同使用习惯提供对话、网页与命令行入口，兼顾非技术用户、进阶用户与 CI 自动化场景。

🤖 AI 客户端对话（最推荐）

把 AgentHub 提供的 MCP 接入 AI 开发客户端后，可在聊天框中用中文描述需求；AI 调用相关 MCP 工具完成搜索、下载、部署与投稿，主要通过对话驱动操作。

🌐 网页端

可视化浏览、关键字搜索、版本切换、审批与权限管理；右上加号下拉发布新资源。

💻 arctl 命令行

进阶与自动化：arctl skill publish / pull / deploy，脚本批量操作，适合 CI 与无界面环境。

核心能力

从发布到上线运行的完整闭环

覆盖多来源发布、资产检索、版本管理、审批工作流、权限分级、一键部署、通知触达。

多来源上传

支持本地 zip、本地文件夹（前端自动打包）、Git 仓库与 Docker 镜像；大文件采用一次性直传 URL，避免 Base64 带来的额外体积开销。

AI 选取 + 关键字过滤

AI 调用 MCP 检索工具拿到全部资产，由模型按用户意图从中选取最匹配项；网页端关键字即时过滤。

版本管理

每次发布创建新版本，保留全部历史；可切换版本、复制完整 JSON、删除指定版本。

审批工作流

pending → 审批通过为 active / 驳回可附理由；管理员在待审批工作台一键处理，状态全程可追溯。

三级角色 + 可见性

user / developer / admin 权限递增；资源可设 public/internal/private/owner-only，按用户组授权细粒度访问。

一键部署

调用部署工具把资源一键部署到指定 Provider，拿到连接地址；Deployed 页统一查看与回收。

飞书通知路由

审批 / 发布通知支持私信、群组、广播；路由在系统管理页实时切换，免改环境变量、免重启。

跨客户端配置生成

为 AI 开发客户端一键生成 MCP 接入配置，降低接入门槛。

敏感信息扫描

发布资产时自动识别疑似硬编码密钥、Token 等敏感信息，并按风险分级提示审核者；凭据内容脱敏展示，辅助审批决策。

对话即操作

AgentHub 对外提供 MCP，供 AI 开发客户端接入

把 AgentHub 提供的 MCP 接入 AI 开发客户端后，用户的一句话会被 AI 拆解为对 registry 工具的调用——使用侧 搜索 → 拉取 / 部署，开发者上传新资产。AI 在检索结果中选取匹配项，再调用部署工具完成上线，减少在多个界面与命令之间切换。

1

自然语言需求

用户在 AI 开发客户端中说“找一个能操作 PG 的 MCP 服务”，AI 自行解析意图。

2

AI 选取

AI 调用 MCP 检索工具拿到资产列表，由模型按意图选取最匹配的资产与版本。

3

拉取 / 部署

调用拉取工具下载安装到本地，或调用部署工具一键部署到 Provider，返回连接地址。

4

自动接入客户端

调用接入工具生成对应客户端的 MCP 配置片段，重启即生效。

5

上传资产

做好新资产（如 Skill）后，AI 调用发布工具自动打包上传，进入 pending 待审批。

技术栈

选型与职责

后端 Go 单体，前端 Next.js；检索复用 PostgreSQL，AI 在 list 结果上选取，部署全容器化。

🧠 协议
Model Context Protocol 工具/资源服务；AgentHub 自身即 MCP Server，供 AI 客户端对话驱动。
🔧 后端
Go + chi 路由 + huma REST/OpenAPI；arctl CLI 同源复用。
🎨 前端
Next.js + Tailwind CSS + shadcn/ui；Sheet 侧边详情、审批与权限管理面板。
🔐 鉴权
JWT（密钥轮换宽限期）+ 飞书 OAuth 登录 + 三级角色（user/developer/admin）+ 资源可见性。
🔢 检索
PostgreSQL 16 关键字检索；AI 在 list 结果上选取；版本树管理。
💬 通知
飞书 lark-oapi 私信 / 群组 Webhook / 广播；路由网页实时切换、免重启。
📦 部署
Docker Compose；UI/API 监听 8080、MCP 监听 8082；上传包走 volume 持久化。
